1. Sistem Mimarisi ve Teknoloji Yığını

Uygulama, eşler arası (Peer-to-Peer) sesli iletişim, gerçek zamanlı DM mesajlaşması ve zengin sosyal özellikler sunan tek kod tabanlı çoklu platform (cross-platform) projesidir.

┌────────────────────────────────────────────────────────────────────────┐ │ İstemci Katmanı (Client) │ │ Expo SDK 56 + React Native 0.85 + React 19 + Expo Router (v56.2) │ │ (Android, iOS ve Web Tek Kod Tabanında) │ └──────────────────┬─────────────────────────────────┬───────────────────┘ │ │ ▼ (WebSocket & REST API) ▼ (Peer-to-Peer Ses Akışı) ┌───────────────────────────────────────┐ ┌──────────────────────────────┐ │ Supabase Platformu │ │ WebRTC Ses Altyapısı │ │ - PostgreSQL + RLS Güvenlik │ │ - react-native-webrtc │ │ - Auth (Anonim, Email, Google OAuth) │ │ - InCallManager │ │ - Realtime (Broadcast/Presence) │ │ - Coturn (STUN/TURN/TURNS) │ │ - Storage (avatars, stories, media) │ │ - Dynamic HMAC-SHA1 Token │ │ - Edge Functions (turn-credentials) │ │ (Supabase Edge Function) │ └───────────────────────────────────────┘ └──────────────────────────────┘
  • İstemci Katmanı: Expo Router ile dosya tabanlı yönlendirme; Android ve iOS'ta native WebRTC modülleri, web ortamında standart W3C WebRTC API'leri kullanılır.
  • Backend Katmanı: Supabase PostgreSQL veritabanı, Row Level Security (RLS) politikaları, Realtime Presence & Broadcast sinyalleşme kanalları ve medya depolama bucket'ları.
  • Ses İletişim Katmanı: P2P doğrudan bağlantı ve kısıtlayıcı ağlar (Symmetric NAT/CGNAT) için Coturn TURN relay sunucusu.

2. Supabase Kurulumu ve Veritabanı Yapılandırması

Adım 1: Proje Oluşturma ve Ortam Değişkenleri

  1. supabase.com adresinde oturum açın ve New Project seçeneği ile yeni bir proje başlatın (Region: Frankfurt / Central EU önerilir).
  2. Proje panosunda Project Settings -> API sayfasına giderek Project URL ve anon public anahtarlarını kopyalayın.
  3. Proje kök dizinindeki .env dosyasını açıp bilgileri girin: 
    EXPO_PUBLIC_SUPABASE_URL=https://<proje-ref>.supabase.co
EXPO_PUBLIC_SUPABASE_ANON_KEY=eyJhbGciOiJIUzI1NiIsInR5cCI6IkpX...
  4. Aynı değişkenleri eas.json dosyasındaki preview ve production profillerinin env alanlarına da tanımlayın.

Adım 2: Veritabanı Şeması ve Migrasyonların Uygulanması

  1. Supabase Dashboard'da sol menüden SQL Editor sekmesini açın.
  2. supabase/schema.sql dosyasının tüm içeriğini yapıştırıp Run butonuna tıklayın.
  3. Ardından supabase/migrations/ klasöründeki 0001'den 0029'a kadar olan migrasyon dosyalarını sırasıyla çalıştırın (veya Supabase CLI ile npx supabase db push yapın).
📌 Oluşturulan Tablolar
profiles, stories, story_likes, conversations, conversation_participants, messages, blocks, reports, daily_matches, system_settings, diamond_transactions, diamond_packages, diamond_withdrawal_requests.

Adım 3: Storage (Depolama) Bucket'ları ve RLS İzinleri

Dashboard -> Storage sekmesinden 3 adet Public bucket açın veya SQL Editor'da şu komutu çalıştırın:

insert into storage.buckets (id, name, public) values 
  ('avatars', 'avatars', true),
  ('chat_media', 'chat_media', true),
  ('stories', 'stories', true)
on conflict (id) do update set public = true;

create policy "Public Select avatars" on storage.objects for select using (bucket_id = 'avatars');
create policy "Public Select chat_media" on storage.objects for select using (bucket_id = 'chat_media');
create policy "Public Select stories" on storage.objects for select using (bucket_id = 'stories');

create policy "Auth Upload avatars" on storage.objects for insert 
  with check (bucket_id = 'avatars' and auth.role() = 'authenticated');
create policy "Auth Upload chat_media" on storage.objects for insert 
  with check (bucket_id = 'chat_media' and auth.role() = 'authenticated');
create policy "Auth Upload stories" on storage.objects for insert 
  with check (bucket_id = 'stories' and auth.role() = 'authenticated');

Adım 4: Realtime (Gerçek Zamanlı) Yayını Açma

Supabase Dashboard -> Database -> Replication sayfasından aşağıdaki tablolar için Realtime seçeneğini ON konumuna getirin:

  • messages (yeni DM mesajlarının anlık düşmesi)
  • conversations ve conversation_participants (sohbet listesi güncellemesi)
  • profiles (çevrimiçi durumları ve VIP rozetleri)
  • stories (anlık hikaye akışı)
  • system_settings ve daily_matches (sistem kotaları ve bakım modu)

Adım 5: İlk Yönetici (Admin) Hesabının Yetkilendirilmesi

UPDATE public.profiles
SET role = 'admin'
WHERE username = 'kullanici_adiniz';

3. WebRTC ve Coturn (STUN/TURN) Sunucu Kurulumu

⚠️ Neden TURN Sunucusu Zorunludur?
Mobil operatör ağları (4G/5G) ve kurumsal Wi-Fi ağları Symmetric NAT / CGNAT arkasındadır. Google STUN doğrudan P2P bağlantı kuramadığında ses aktarımı kilitlenir. Coturn TURN sunucusu, şifreli ses paketlerini güvenle aktararak (Relay) bağlantı başarı oranını %99.9'a çıkarır.

Adım 1: Linux VPS ve DNS Hazırlığı

  1. Ubuntu 22.04 / 24.04 LTS kurulu bir VPS sunucusu hazırlayın (1 CPU, 1-2 GB RAM yeterlidir).
  2. DNS sağlayıcınızdan bir A Kaydı oluşturun:
    turn.sitedomain.com ➔ VPS_IP_ADRESI

Adım 2: Paketlerin Kurulumu ve SSL Sertifikası

sudo apt update && sudo apt upgrade -y
sudo apt install -y coturn certbot

# Let's Encrypt ile ücretsiz SSL sertifikası alın
sudo certbot certonly --standalone -d turn.sitedomain.com

Adım 3: Sertifikaların Yetkilendirilmesi ve Güvenli Secret Üretimi

sudo mkdir -p /etc/coturn/certs
sudo cp /etc/letsencrypt/live/turn.sitedomain.com/fullchain.pem /etc/coturn/certs/
sudo cp /etc/letsencrypt/live/turn.sitedomain.com/privkey.pem /etc/coturn/certs/
sudo chown -R turnserver:turnserver /etc/coturn/certs
sudo chmod 640 /etc/coturn/certs/*

# 32 karakterlik güçlü statik secret üretin:
openssl rand -hex 32
# Örnek çıktı: 4a8f9c2d7e1b5a0f6e3c8d2a1b9f4e7c8a0d2f4b6e8a1c3e5f7a9b0c2d4e6f8a

Adım 4: /etc/turnserver.conf Yapılandırma Dosyası

listening-port=3478
tls-listening-port=5349

realm=turn.sitedomain.com
server-name=turn.sitedomain.com

# Supabase Edge Function ile dinamik token kullanımı (HMAC-SHA1)
use-auth-secret
static-auth-secret=BURAYA_URETTIGINIZ_SECRET_YAZIN

# Medya Aktarım (Relay) UDP Port Aralığı
min-port=49152
max-port=65535

# TLS / DTLS Sertifikaları
cert=/etc/coturn/certs/fullchain.pem
pkey=/etc/coturn/certs/privkey.pem

fingerprint
lt-cred-mech
no-cli
no-loopback-peers
no-multicast-peers
stale-nonce=600
log-file=/var/log/turnserver/turnserver.log

Coturn servisini etkinleştirmek için /etc/default/coturn dosyasını açıp TURNSERVER_ENABLED=1 yapın:

sudo sed -i 's/#TURNSERVER_ENABLED=1/TURNSERVER_ENABLED=1/' /etc/default/coturn

Adım 5: Güvenlik Duvarı (UFW) Portları ve Başlatma

sudo ufw allow 3478/tcp
sudo ufw allow 3478/udp
sudo ufw allow 5349/tcp
sudo ufw allow 5349/udp
sudo ufw allow 49152:65535/udp
sudo ufw reload

# Servisi başlatın ve kontrol edin
sudo systemctl restart coturn
sudo systemctl status coturn

Adım 6: Supabase Edge Function (turn-credentials) Dağıtımı

Uygulama, güvenliği sağlamak için TURN sunucusunun kalıcı şifresini istemciye asla göndermez. Kullanıcılar her çağrı öncesi 10 dakika geçerli tek kullanımlık HMAC-SHA1 jetonu alır.

# Proje dizininde secret'ları Supabase'e tanıtın:
npx supabase secrets set TURN_SECRET="URETTIGINIZ_SECRET" TURN_DOMAIN="turn.sitedomain.com" TURN_TTL_SECONDS="600"

# Edge Function'ı deploy edin:
npx supabase functions deploy turn-credentials

4. Android Uygulama Derleme (Build & Release)

Ön Hazırlıklar

  1. Firebase Console'dan projenize ait google-services.json dosyasını indirip proje kök dizinine yerleştirin.
  2. app.json içerisinde gerekli mikrofon, kamera ve Bluetooth izinleri eksiksiz tanımlanmıştır.

Yöntem A: EAS Cloud Build (Önerilen)

Yerel bilgisayarınızda Java/Android SDK kurmaya gerek kalmadan Expo sunucularında doğrudan derleme alabilirsiniz:

# Expo hesabınıza giriş yapın
npx eas-cli login

# Test için kurulabilir doğrudan APK üretimi:
npx eas-cli build --platform android --profile preview

# Google Play Store için AAB (App Bundle) üretimi:
npx eas-cli build --platform android --profile production

Yöntem B: Yerel Makinede Gradle ile Derleme

# Temiz native prebuild oluşturun
npx expo prebuild --platform android --clean

# Release APK derleyin
cd android
.\gradlew.bat assembleRelease
cd ..

APK Dosya Konumu: android/app/build/outputs/apk/release/app-release.apk

Ön Hazırlıklar

6. Web Uygulaması Derleme ve Yayınlama (Hosting)

🔒 HTTPS Zorunluluğu
WebRTC mikrofon ve ses donanımı erişimi modern tarayıcılarda güvenlik gereği yalnızca HTTPS bağlantılarda (https://) veya yerel testlerde (localhost) çalışır.

Yerel Web Testi:

npm run web

Statik Web Dağıtım Paketi (Bundle) Üretme:

npx expo export -p web

Bu komut kök dizinde optimize edilmiş bir dist klasörü oluşturur.

Firebase Hosting ile Yayınlama:

# firebase.json dosyasında "public": "dist" olduğunu doğrulayın, ardından:
npx expo export -p web
firebase deploy --only hosting

7. Hata Ayıklama (Troubleshooting) ve Kontrol Listesi

Belirti / Hata Olası Neden Çözüm Adımı
Arama "Bağlanıyor..."da takılıyor 1. Coturn servisi çalışmıyor.
2. UDP Relay portları (49152:65535) kapalı.
3. Edge Function secret'ları hatalı.		 Sunucuda sudo systemctl status coturn ve sudo ufw status kontrol edin. Trickle ICE aracında relay adayı çıktığını doğrulayın.
Android 12+ Cihazda Karşı Tarafa Ses Gitmiyor BLUETOOTH_CONNECT çalışma zamanı izni verilmemiş. Kullanıcının Bluetooth ve Mikrofon iznini onayladığını teyit edin (CallContext içerisinde otomatik sorulur).
Ses Ahize Yerine Hoparlörden Geliyor InCallManager başlatılamadı. InCallManager.start({ media: 'audio' }) çağrısının yapıldığından ve setSpeakerphoneOn(false) varsayılanında olduğundan emin olun.
Resim / Story Yüklenirken 403 Forbidden Supabase Storage RLS kuralı veya Public ayarı eksik. avatars, chat_media ve stories bucket'larının "Public" olduğunu ve authenticated yükleme politikasını kontrol edin.
Mesajlar Sayfa Yenilenmeden Düşmüyor Supabase Database Replication kapalı. Supabase Dashboard -> Database -> Replication -> messages tablosunun toggle'ını aktif edin.

Canlıya Çıkış Kontrol Listesi (Deployment Checklist)

  • Supabase: schema.sql ve 0001-0029 migrasyonları uygulandı.
  • Supabase Realtime: messages, profiles, conversations, stories tabloları Replication'a eklendi.
  • Supabase Storage: avatars, chat_media, stories bucket'ları Public olarak açıldı ve RLS ilkeleri eklendi.
  • Coturn STUN/TURN: VPS'e kuruldu, SSL bağlandı, 3478/5349 TCP/UDP ve 49152-65535 UDP portları açıldı.
  • Edge Function: turn-credentials fonksiyonu yüklendi; TURN_SECRET ve TURN_DOMAIN tanımlandı.
  • Ortam Değişkenleri: .env ve eas.json içine Supabase URL ve Anon Key tanımlandı.
  • Firebase: google-services.json kök dizine eklendi.
  • Admin Hesabı: İlk yöneticinin rolü role = 'admin' olarak ayarlandı.
  • Test Derlemesi: npx eas-cli build --platform android --profile preview ile APK alınıp gerçek cihazda sesli görüşme test edildi.
